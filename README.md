# Engenharia-de-Software

Nesta disciplina, conhecemos a história e os fundamentos da Engenharia de Software, entendendo seus objetivos e sua importância no desenvolvimento de sistemas. Também estudamos os critérios de qualidade de software e os componentes que formam um sistema. Esses aprendizados contribuíram para compreender como desenvolver soluções bem estruturadas, funcionais e confiáveis.
